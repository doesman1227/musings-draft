JAL×Hiltonマイル最適化ダッシュボード構想

JAL × Hilton Travel Rewards Optimizer

概要

JALカード（Club-A/Gold）とHilton Amex（Standard/Premium）を併用するユーザー向けに、年間利用額の最適配分を計算しマイル・宿泊特典の価値を最大化するインタラクティブダッシュボードの設計。 デフォルト条件（年間300万円利用）ではHilton全額配分が最適（年間52万円相当）という試算結果と、その計算ロジック（JAL式・Hilton式・最適配分探索）をまとめた。 Vanilla JS + Chart.jsによる静的サイトとして実装済みで、スライダーによるシミュレーションと5年間の累積推移を可視化する。

[!info] 概要 JALカード（Club-A / Club-A Gold）とHilton Amex（Standard / Premium）の両方を保有するユーザー向けに、年間カード利用額の最適配分を計算し、マイルと無料宿泊特典の価値を最大化するインタラクティブダッシュボード。

計算モデル

価値評価の前提（ASSUMPTIONS）

最適化アルゴリズム

  1. 0%〜100%を1%刻みでJAL/Hilton配分を全パターン計算
  2. 各配分で以下を算出:
  • JAL: カードマイル + フライトボーナス + 特典航空券 + ラウンジ + Class Jアップグレード + 保険 − 年会費
  • Hilton: カードポイント + ホテルポイント + ステータスボーナス + 無料宿泊特典 + ステータス特典 − 年会費
  1. 合計純リワード価値 = JAL純利益 + Hilton純利益 が最大となる配分を推奨

年別計算（5年間）

  • 毎年同じ利用パターンを仮定
  • マイル・ポイントは繰越（年間累積）
  • 無料宿泊特典は毎年再獲得
  • 累積マイル/ポイント × 単価 = 累積価値

計算ロジックの詳細

JAL計算式

カードマイル = floor(JAL利用額 / mileRate)
  Club-A: mileRate = 200 → ¥200 = 1マイル
  Club-A Gold: mileRate = 100 → ¥100 = 1マイル

フライトボーナス = floor(フライト回数 × 800 × 0.25)

総マイル = カードマイル + フライトボーナス

マイル価値 = 総マイル × ¥2

特典航空券 = floor(総マイル / 8,500) × ¥25,000

Class Jアップグレード = min(フライト数, floor(総マイル / 10,000)) × ¥3,000

ラウンジ価値 = Club-A Gold のみ: フライト数 × ¥1,000

総価値 = マイル価値 + 特典航空券 + アップグレード + ラウンジ + 保険
純利益 = 総価値 − 年会費

Hilton計算式

カードポイント = floor(Hilton利用額 / 100 × pointRate)
  Standard: 2pt / Premium: 3pt

ホテル宿泊ポイント = floor(泊数 × ¥30,000 / 100 × hiltonPointRate)
  Standard: 3pt / Premium: 7pt

ステータスボーナス = floor(泊数 × 1,500 × bonusPct)
  Gold: 80% / Diamond: 100%

総ポイント = カードポイント + ホテルポイント + ステータスボーナス

ポイント価値 = 総ポイント × ¥0.5

無料宿泊特典:
  Standard: ¥150万利用 → 1泊
  Premium: 無条件1泊 + ¥300万利用で2泊目

ステータス特典価値 (Gold):
  朝食 = 泊数 × ¥5,000
  アップグレード = 泊数 × ¥10,000
  レイトチェックアウト = ceil(泊数/3) × ¥3,000

Diamond追加価値 = 泊数 × ¥5,000

総価値 = ポイント価値 + 無料宿泊 + ステータス特典
純利益 = 総価値 − 年会費

最適配分計算

for split = 0 to 100 (step 1):
  state.split = split
  result = calculateTotal()
  if result.totalNet > best.totalNet:
    best = { split, value: result.totalNet }
推奨配分 = best.split
